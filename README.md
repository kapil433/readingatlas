# The Reading Atlas

A self-contained, offline-friendly literary discovery library spanning countries, centuries, genres, and ideas. Explore **1,412 entries across nine interactive collections**, with reading notes, filters, saved lists, and progress tracking.

## Open the atlas

1. Download [index.html](index.html) using GitHub's **Download raw file** option.
2. Open it in a modern browser.
3. Switch between the nine tabs and explore at your own pace.

All layouts, scripts, and collection data are embedded in the single HTML file. No installation, build tools, account, or server is required. External source and edition-search links require an internet connection.

The file is named `index.html` so it can also serve as the home page on a static host such as GitHub Pages. Uploading the file alone does not enable Pages hosting.

## Features

- Original layouts and interactions preserved for the three supplied collections; the six newer shelves share their navy/teal palette, serif heading hierarchy, white cards, and responsive layout.
- Search and collection-specific filters for country, period, language, genre, form, or prize.
- Chronological science fiction browsing.
- 100 contemporary selections with reading-route filters (Nobel, Booker, other prizes, critics, bestsellers and booksellers), separate publication and selection years, translator credits, and per-entry source links.
- Fifty author paths with starting works, suggested sequences, and practical scope notes.
- Essays, poems, and stories grouped by form, country, period, or theme.
- Browser-local saved/read tracking and reading-list backup controls on applicable shelves.
- Keyboard navigation between the main tabs and responsive layouts.

Tracking belongs to the browser and origin where the file is opened. Earlier collections retain their original storage and controls; new sections have their own backup formats. Use the relevant export controls before changing devices or browsers.

## Selection and prize notes

The selections are editorial reading recommendations. Short-novel boundaries vary by edition and translation. Rediscovered works may be available in modern reprints.

The contemporary shelf uses **selection/prize year** (including a review list or dated bestseller chart), while displaying original publication or a specified edition separately. An older work can therefore appear in a recent prize-year selection.

A **Nobel Prize in Literature badge identifies an author laureate**, and the accompanying book is a suggested entry point into that author's work. Book-prize winners, shortlists, and longlists are labelled separately.

Prize information is a snapshot checked on **19 October 2026**, with awarding-body sources linked inside the atlas. The shelf was expanded on **20 October 2026** using Literary Hub, TIME, The New Yorker, Kirkus, Publishers Weekly/AP, bookseller lists, and publishers. Bestseller labels describe the cited historical chart or publisher claim, rather than a live sales ranking. The file does not update automatically.

## About the content

This is a reading guide with bibliographic entries and original reading notes. It does not include the complete texts of the recommended copyrighted books, essays, poems, or stories.
